# Mac 无用小玩具：开发进度

最后更新：2026-09-24；本机正式版 1.0.0 / 13。以下 0.8 及更早章节是历史记录，以本节的 1.0 状态为准。

## 1.0 摄影棚布光与正式版

用户最新要求与三条已保存批注对应：摄影棚上下翻转、灯光控件间距、三维多光源和实体灯具。前两项沿用已完成的 0.7 改动；本版把布光台直接放进摄影棚的第二页，较矮窗口可滚动，主界面与菜单入口都可直接打开。内容展厅的窗口、入口、资源生成代码和专项测试已删除；本机批注 JSON 保留为私有历史，不进入发布包。

手电筒和摄影灯新增可保存的方位／仰角；按住“调向”按钮拖动时，三维灯具方向、桌面模型上的光束、Metal 照明范围与阴影一起改变。火焰灯具各有不同亮度与衰减，蜡烛和火柴的光轻微闪烁并随演示时间燃尽；蜡烛实体同步缩短，可重新点燃。太阳以 240 秒演示周期从东到西移动，夜间替换为较弱的冷色月亮；可“跳到夜晚”检查。该机制是实时近似，不是严格的真实天文或完整路径追踪。

正式版显示程序坞图标，Info.plist 为 1.0.0 / 13、普通应用模式；紫色图标与当前界面配色一致。已在本机重新构建并通过临时签名验证。自动检查覆盖旧版图标轮廓／位置／换色／阴影、21 项性能策略、光线求交管线，以及新增的朝向持久化、旧存档迁移、转向前后真实 GPU 像素差异、蜡烛燃尽和昼夜状态。原生短测中按住拖动手电筒，方位从约 71° 到 114°；三灯同时运行 GPU 错误为 0，内存压力正常；太阳切换成月亮，蜡烛加速到约一半寿命后模型变短、显示约 48% 剩余。诊断和截图见 `work/qa-v100` 及 `outputs/闲着-1.0-*.png`。

重要边界：删除展厅后，1.0 没有主动扩张的大内存玩法，旧随机填充也没有恢复。因此不能将当前动画写成已占满多余物理内存，更不能保证任何机器使用几十 GB。持续绘制会使用可退让的 GPU 计算资源。用户的审美、长时间热量与内存压力、真实睡眠、多显示器、其他 Mac 和 Intel 均未完成验收；本地签名未公证。GitHub 1.0 源码和 ZIP 的实际发布核对另记录于本节末尾。

## 0.8 三维布光与多光源

用户认为展厅作品观感未达要求，要求先搁置。保留默认关闭的现有展厅及释放能力；暂停作品美术和“作品选到桌面”，不将容量扩展写成本轮成果。新范围与分级门槛见《0.8三维多光源分级计划.md》，原始批注仍在《0.7审阅批注.json》。

- 一级：保留旧主灯设置，新增最多三盏辅助灯，总计四盏。每盏独立选择摄影灯、手电筒、太阳、打火机、蜡烛、火柴，控制开关、三维位置、亮度和颜色，保存后可重启恢复。原简易调光板仍可调主灯。
- 二级：新布光台用等距网格显示图标、灯具和高度；点选、拖动平移、Option 拖动高度，右侧滑杆精调。模型与小范围光晕可在模拟桌面和真实悬浮图标附近一键隐藏；悬浮窗口保持鼠标穿透。主界面、菜单栏和摄影棚均有入口。
- 三级：Metal 同时计算多灯照明与独立阴影。手电筒聚光、太阳宽光、火焰近距离衰减和轻微闪烁；它们是实时近似。两灯硬件求交短测偶见很慢的单帧，因此多灯采用独立阴影图，单灯在预算允许时仍可用硬件光线求交承影。GPU/系统保护先降低采样与辅助灯的投影数量，避免空灯占用阴影贴图。布光台显示近期可见动画帧的 GPU 时间估计，此数值不是整机 GPU 使用率。
- 用户追加灯具美术返修：拒绝看起来像贴上 emoji 的扁平图形。现以三维几何面生成六款实体灯具，按面法线明暗表现厚度。手电筒增加独立筒身、金属头、开关与发光透镜；摄影灯有灯箱／支架，打火机有机身／金属顶盖／火轮，蜡烛与火柴有实体、灯芯或火柴头及火焰。它们在布光台、模拟桌面、真实悬浮层共用绘制方式，无 emoji 图片。桌面模型适当放大，但仍限制在玩具透明区域内并保持鼠标穿透。

本机原生检查：实际添加辅助灯、拖动位置、滑杆调整高度、切换为蜡烛、删除灯具、模型开关和四灯并行均反馈到界面及诊断状态。返修后四款实体灯具同屏见 `outputs/闲着-0.8-三维布光台.png`；六款放大图见 `outputs/闲着-0.8-灯具模型预览.png`；模拟桌面见 `outputs/闲着-0.8-桌面预览.png`，真实悬浮层见 `work/qa-v080/desktop-lamp-model.png`。之前发现未添加灯具因亮度钳制被错误计入阴影资源，已修正；单灯／精细档的阴影纹理约 4 MiB，四灯／极细档约 64 MiB（档位不同，不能将两数当成同条件增量）。四灯短测 GPU 错误 0、系统内存压力正常；测试灯已删除，用户原有灯位和其他偏好恢复。

自动检查：返修后 `work/qa-v080/appearance-model.log` 多灯 GPU 对照、孔洞与桌面阴影、旧外观回归通过；`work/qa-v080/ray-model.log` 多灯光追管线编译及单灯几何求交通过；`work/qa-v080/performance.log` 21 项策略模拟通过；`work/qa-v080/gallery.log` 旧展厅资源释放回归通过。最终应用构建与本地签名见 `work/qa-v080/build-model-delivery.log`。两灯原生诊断中硬件光追按保护策略关闭、独立阴影照常生效，GPU 错误 0、悬浮层鼠标穿透为 true；短时 GPU 时间曾在约 2–14 ms/帧间变化，随采样与窗口状态波动，不当成持续基准。逐项批注页已增加布光台、多灯桌面预览及六款模型逐盏批注，旧批注原文与分区键未改。

较矮窗口已验证可滚动到底部控件。真实高温/内存压力、睡眠、多显示器、长期使用和其他机型未完成实机检查；灯具外观与手感待用户审阅。当前只证明本机短时功能和基本退让，不保证任意电脑都能始终无感满载。完整本地交付包和普通启动核对记录见本节末尾。
