# 0.7 持续渲染与可选内存展厅

2026-09-23 用户确认：先让 GPU 持续绘制，根据余力自动调强度，再接真实光追；内存展厅为可选玩法。完成后提供能逐部分批注的审阅入口，按注释修改。

## 分段交付

1. 0.7A：当前图标实时提升阴影采样精度和柔和度。将采样量作为可调工作量，依 GPU 完成耗时、温度、低电量及内存压力调节。暂停、睡眠和高压力立即降负载。界面显示当前采样级与实测 GPU 时间。不能把多次过滤称为光追。
2. 0.7B：硬件支持时接入 Metal 加速结构与光线求交，使光线实际与图标几何相交，先用于桌面与摄影棚阴影，并和 0.7A 的预算器共用退让。设备不支持时保留既有渲染。反射和间接光另作后续任务，不能把当前投影称为完整路径追踪。GPU 预算需要本机可停止的短测和对照图。
3. 0.7C：可选内存展厅。默认关闭；打开后生成可浏览、可删除、可选择桌面展示的不同作品。显示资源分配和进程负担，监测压力后逐块释放。不要恢复旧随机填充。32 GiB 机器和高内存机器分别测上限，不承诺固定 80%。
4. 审阅：主界面、桌面效果、摄影棚、渲染强度、内存展厅分别编号出图，提供逐项可写的反馈入口；标清已实现与待实现。用户批注后逐项关闭。
