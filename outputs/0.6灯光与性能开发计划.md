# 0.6 灯光与性能开发计划

2026-09-22：用户授权“开始构建操作，记得做好规划”。0.5 外观已认可。

## 本轮交付范围

1. 保留 0.5 回退点，审查现有渲染与暂停行为。
2. 增加可拖动灯光、亮度和颜色；检视窗口加入摄影棚承影背景。通过真实几何深度生成阴影，保留孔洞；不将其称为光追。桌面透明悬浮保持透明。
3. 加入日常陪伴、尽兴展示两种自动预算，以及手动画质档位。按 GPU 单帧耗时、系统内存压力、系统温度状态及低电量模式下调；稳定后缓慢恢复。限制同时在途帧，避免堆积。暂停、隐藏、睡眠仍停止连续绘制。
4. 展示实际 GPU 帧耗时、当前画质与目标帧率；明确这不是整机 GPU 使用率或实测温度。保存灯光及模式设置。
5. 验证灯光移动改变阴影、孔洞仍透光、质量档切换、保护策略、暂停与退出；保留实际 GPU 输出、原生交互及构建证据。
6. 打包可运行版本，用户检查布光效果和操作手感；D 全量体验仍单独记录。

## 验收与边界

- 自动升档有稳定等待时间，降档有冷却，不能逐秒来回跳。
- 无意义填充仍停用。本轮增加真实渲染计算，未完成可浏览大内存资源池；后续继续该产品目标。
- 光追、作品资源池、跨机型兼容、长时间日常体验列后续，不伪称完成。
- 本轮不以跑满 GPU、固定内存百分比或具体温度为目标，不进行无上限压力运行。
- 回退目录：work/checkpoints/before-v06；测试证据：work/qa-v06。
