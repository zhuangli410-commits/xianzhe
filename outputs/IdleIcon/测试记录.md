# 0.5 视觉小样检查记录

日期：2026-09-22。实机 Apple M5 / 32 GiB / macOS 26.6.2，arm64。部署目标 macOS 14，未据此声称已经跨系统验证。

## 本轮纠正

用户明确反馈 0.4 侧面仍有条纹，故撤回“侧面问题已解决”的完成结论。0.4 大量随机噪声缓存的视觉收益很小，0.5 停用其所有产品启动入口，保留预算代码供后续真实资源重建；本轮没有进行填充占用试验，不拿历史噪声测试证明新资源池有效。

## 新实现

- 独立平滑侧面颜色分布，避免将边缘像素和阴影拉成贯穿厚度的条纹；正面保留原图细节。
- 闭合轮廓进一步平滑，前后边缘生成真实多段倒角，法线从正面连续过渡到侧面；保留孔洞。
- 多种原色映射到同一目标色时共享亮度基准，消除原色分组边界人为产生的色带。
- 独立大图检视，拖动、滚轮、角度滑杆、厚度、材质、自动旋转和视角重置；材质和厚度保存并同步到桌面。
- 静止检视和隐藏检视窗口停止连续绘制；更改控件时按需更新。

## 已验证

- 合成条纹输入经过侧面颜色处理后，高频亮暗变化得到抑制；没有通过申请填充数据实现该效果。
- 倒角顶点存在从正面到侧面的过渡法线，法线有限且归一化；圆环孔洞保留，轮廓交并比超过 98.5%。
- 同色换色渐变与统一连续变换逐像素一致（允许 1 字节取整误差），透明度和恢复仍通过原有检查。
- 拖动事件测试包含 delta 为零的合成事件，使用实际位置差；旧实现依赖 delta 的问题在实际检视检查中发现后修正。
- ChatGPT、Chrome、微信、Safari 真实 Metal 渲染：同一斜侧面与接近侧面；另检查正面、哑光／金属、不同厚度、纯色与换色。
- 原有 27 组位置映射、模拟桌面拖动、孔洞、旋转暂停和五份应用素材回归通过。
- 原生界面实际操作：角度滑杆设到 78°；拖动后变为约 115.8°；滚轮后缩放到约 1.3 倍；金属材质与 1.8 倍厚度可应用。
- 检视自动转动时帧计数从 230 增至 1275；关闭后停止连续绘制。具体数值是提交帧数，不等于显示器呈现帧率。
- 小样运行时旧材质池为 0，填充开关为关闭，图标本身正常显示；这证明旧路径停用，不代表新批量作品池已实现。

证据：work/qa-v05/appearance-final.log、appearance/appearance-tests.json、geometry.log、test-results.json、native-orbit-zoom.json、native-material-thickness.json、native-auto-a.json、native-auto-b.json、closed-a.json、closed-b.json。真实近侧面截图：work/qa-v05/native-near-side.png。
