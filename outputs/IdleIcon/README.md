# 闲着 0.6.1 · 桌面光影

桌面图标现在也有透明投影，与摄影棚同步。图标保持原大小和位置，鼠标可穿透；影子超出屏幕的部分自然裁切。这是虚拟承影面上的几何投影，不会读取其他软件窗口的立体形状。

**随时调灯：**菜单栏选择“随时调节桌面灯光”，或主面板点击“桌面调光”。悬浮小面板里拖动黄色光点，或用左右、上下、远近滑杆精调。亮度、灯色和灯位实时同步并保存，关闭摄影棚后仍有效；暂停动画时也能按需调光。

本机检查与限制见上一级《开发进度.md》《0.6.1桌面光影计划.md》。光追和大内存作品池尚未实现；旧随机填充不恢复。以下为 0.6 基础功能说明，其中“桌面保持透明”在 0.6.1 包含半透明影子，不含摄影棚底板。

# 闲着 0.6 · 灯光摄影棚

本版增加可玩灯光、实时投影和自动画质，保留已认可的轮廓、材质与换色。大内存作品资源池尚未实现；旧随机填充停用，主动利用闲置内存的目标仍保留。

## 怎么玩

打开“闲着.app”，点击“灯光摄影棚 · 放大把玩”。

- 勾选“拖动灯光”，在大图内拖动灯位；也可按住 Shift 拖动。取消勾选后恢复转动图标，滚轮缩放。
- 亮度滑杆调整强弱，灯色菜单选择暖白、日光、冰蓝、紫色；颜色框提供系统自定义入口。灯位、亮度与颜色会保存。
- 摄影棚背景接收图标真实几何的投影，孔洞透光。桌面悬浮仍透明。这是阴影贴图，不是光追。
- 日常陪伴：最高精细、目标 30 帧。尽兴展示：稳定后逐级升至极细、目标 60 帧。手动上限：指定最高画质，仍服从系统压力保护。
- 画质调整阴影分辨率和过滤精度；负载高或系统压力出现时退让，连续稳定至少 20 秒再升档。
- GPU ms/帧是摄影棚最近完成帧的平滑耗时；静止时保留最近值，不是整机 GPU 使用率。目标帧率不是持续实测帧率，也不保证不影响其他工作。
- 切换哑光、陶瓷、金属，调整厚度；主面板可拖动桌面位置、设置大小与转速、换色和恢复原色。
- 勾选自动转动看动画；重置观察角度返回斜侧面；重置灯光返回暖白默认灯位。
- 关闭摄影棚停止其连续绘制。主面板“暂停并释放”暂停动画；完全结束点“退出”。

## 边界与验证

按轮廓挤出的立体物体仍不是完整 AI 三维模型，原图自带的细节和浮雕阴影仍保留在正面。复杂图标可调整抠图方式。

无意义随机填充已停用；本版不会自动占用几十 GB，真实作品资源池、光追列后续。摄影棚投影落在虚拟背景，不会读出 Mac 其他窗口的立体深度。灯光采用正交投影与过滤阴影，尚不是物理面积光源。

本机验证 Apple M5 / 32 GiB / macOS 26.6.2。arm64、macOS 14 部署目标；其他机型未实测。仅本地临时签名，未公证。无账户、云服务或开机启动。

构建、几何外观、真实 GPU 阴影、策略模拟和原生交互已检查。真实睡眠、多显示器、长时间日常体验、其他机器尚未验收。四色预设已实测，自定义系统颜色面板未完成端到端操作检查。

## 开发入口

- 上一级《第一版开发操作手册.md》《开发进度.md》《0.6灯光与性能开发计划.md》记录范围、状态与证据。
- Source/IconRenderer.swift：轮廓挤出、侧面涂色、材质、灯光和阴影。
- Source/PerformanceBudget.swift：纯画质预算策略。
- Source/InspectorCanvas.swift、main.swift：交互、保存、跟随、生命周期和界面。
- Source/MemoryPlayground.swift：旧策略与历史填充代码仅作参考；产品入口不会调用随机填充。
- build.sh：退出软件后构建。
- test.sh：几何、坐标、拖动和旋转回归。
- test-appearance.sh：轮廓、配色、灯光拖动、GPU 多角度、投影及孔洞透光。
- test-performance.sh：画质降档、冷却、恢复、压力／温度／省电策略模拟。

完整使用手感由用户检查，不把编译或模拟结果当成最终体验验收。
