# 闲着 1.0 · 使用说明

打开“闲着.app”后，它会识别当前正在使用的应用，把图标变成立体旋转动画。主窗口里的模拟桌面可直接拖动图标；右侧调整大小、速度和抠图，下方更换图标颜色。桌面上的悬浮图标允许鼠标穿透。

点击“打开摄影棚”，在“画面与材质”页查看大图、旋转视角、调整材质和厚度。切到“三维布光”，即可添加最多三盏辅助灯（加主灯共四盏）。在三维台上拖动灯具可平移，按住 Option 拖动可改变高度；右侧可精调位置、亮度、光色和开关。手电筒或摄影灯选中时，**按住“调向”按钮并拖动**，模型方向、光束和投影会同步改变；其他灯向四周照射或自动移动，所以不显示可用的调向按钮。

蜡烛会轻微闪烁，约十分钟演示时间里逐渐变短直至熄灭；火柴约四十五秒燃尽，“重新点燃”可重启。太阳用四分钟完成一轮演示昼夜，白天从东到西移动，夜间显示冷色、较暗的月亮；“跳到夜晚”可快速查看。这些时间为玩具演示时间，并不跟随当地日出日落。摄影灯、手电筒、太阳、月亮、打火机、蜡烛和火柴的亮度与光线范围不同。

灯光和阴影会同步到摄影棚、模拟桌面与桌面悬浮图标。关闭窗口不一定退出软件；从菜单栏选“退出闲着”才完全结束。主窗口的“暂停动画”会暂停持续绘制，系统繁忙时自动画质也会降低绘制负担。

内容展厅已删除。1.0 不会为了占数字而填充大量随机内存，也不能保证耗尽空余 RAM；目前主要利用空闲计算能力进行可见的实时光影。若要在本机逐块批注界面，运行上一级的“打开逐项批注.command”。

仅在 Apple M5 / 32 GiB 上做了短时检查；其他机型、长时热量与内存压力、睡眠和多屏体验尚未验收。应用为本地临时签名，未公证。技术检查与用户观感分别记录在上一级《开发进度.md》和本目录《测试记录.md》。
